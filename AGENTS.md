# Agent rules for flarialmc/Flarial.Launcher

These rules apply only to the flarialmc/Flarial.Launcher repository.

## Pull requests

1. Work on a task branch. Push only to that branch, never to `main`.
2. Open a pull request for code review and approval by a human maintainer.
3. Notify human maintainers with the PR link and the validation you ran.
4. Stop after the handoff. Leave the PR open for human review.

## Merging

Only human maintainers merge pull requests. Agents never merge a PR or enable auto-merge, even when asked to or after approval.
